# 🎯</> IS311 Full Stack Web Development

Welcome to the official GitHub repository for **IS311**, a course offered at **Prince Sultan University** under the **College of Computer & Information Sciences**. This repository contains lecture materials, code examples, projects, and resources for learning **Full Stack Web Development** - a comprehensive curriculum covering frontend (HTML, CSS, JavaScript, Bootstrap) and backend (Node.js, MySQL) development. It includes projects, lecture notes, and resources for building modern web applications.

## 📚 Course Overview

This course provides a structured introduction to modern full-stack web development, equipping students with the skills to design, build, and deploy dynamic, responsive web applications. Starting with the foundations of the internet and core web technologies, the curriculum progresses through frontend development with HTML, CSS, JavaScript, and Bootstrap, and advances to server-side programming with Node.js and MySQL. Through hands-on projects and real-world examples, learners will gain practical experience in creating fully functional web solutions from scratch.

## What You’ll Learn:

🌐 Web Fundamentals: History of the internet, how browsers work, DNS, and core web technologies
🎨 Frontend Mastery: HTML5, CSS3, JavaScript (ES6+), and Bootstrap for stunning, mobile-friendly designs
⚙️ Backend Power: Node.js, Express, and MySQL to create robust servers and databases
🔗 Full-Stack Integration: Connect your frontend and backend to build complete, interactive applications
📦 Real Projects: Capstone project to showcase in your portfolio

## Why Take This Course?

✅ Step-by-step, beginner-friendly approach
✅ Blend of theory and hands-on coding
✅ Build a professional portfolio piece
✅ Prepare for internships, jobs, or further study in web development
